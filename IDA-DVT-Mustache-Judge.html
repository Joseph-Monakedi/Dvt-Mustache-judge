Section 01

Architecture Overview

The solution pairs an engaging React client with a lightweight, robust ASP.NET Core backend. Image ingest is guided in the browser by an optical mustache target HUD, processed via Gemini 2.0 Flash for structured comedic yet metric-based evaluation, and broadcast instantly to a shared Movember leaderboard.

EXP

Experience Layer (React + Vite)

Responsive client featuring a live webcam viewport with animated mustache alignment reticle, instant snapshot preview, fallback drag-and-drop file upload, real-time verdict suspense reveal, and a high-impact DVT-branded Leaderboard view with office kiosk presentation mode.

API

Application & Ingestion Plane (ASP.NET Core 8 Web API)

Receives multipart submissions (name, cohort, photo), executes input sanitization and payload throttling, persists assets to high-speed cloud storage, invokes the Gemini evaluation pipeline, and updates the leaderboard database in a single resilient transaction.

AI

Evaluation Engine (Google Gemini 2.0 Flash / 1.5 Flash)

Multimodal vision analysis prompted with strict JSON schema constraints. Evaluates facial hair across Density, Symmetry, Bristle Swagger, and Style; generates an affectionate comedic roast, mustache archetype title, and celebrity twin match.

STR

Data & Asset Storage (Zero-Cost Free Tier)

Images stored on Cloudinary (25GB free tier with automatic facial smart-cropping CDN URLs) or Supabase Storage (1GB free tier). Structured judge records and rankings stored in Supabase PostgreSQL (or SQLite/EF Core for local zero-config runs).

OPS

Office Kiosk & Operations Plane

Auto-refreshing live leaderboard, QR code generator for mobile participant check-in, and moderation override endpoints allowing graduate facilitators to flag or remove accidental photobombs live during the 1 November kickoff.

Reusable Platform Modules

📷 Optical Guide Overlay

Self-contained React canvas/SVG overlay with face oval + mustache target bracket, distance feedback, and mobile touch capture support. Adaptable to any badge or credential verification app.

⚡ Gemini Vision Pipeline

Configurable .NET GenAI service supporting schema-enforced multimodal output, system instructions, temperature tuning, and fallback error handling against rate limits.

🏆 Live Leaderboard Engine

Normalized scoring, percentile rank calculator, category filters ("Top Stache", "Funniest Roast", "Most Improved"), and lightweight polling/SSE stream.

☁️ Cloud Asset Adaptor

Clean C# repository interface (IImageStorageService) with swappable implementations for Cloudinary, Supabase S3, and Local File Disk storage for offline testing.

Hard Invariant: The Kindness & Consent Guardrail. All Gemini prompts must enforce: "Critique only the mustache grooming, density, and style. Never insult the human, their features, or skin. Ensure roasts are witty, affectionate, and workplace-safe." Submissions require no authentication but enforce explicit client-side consent.

Section 02

Intent Driven Architecture Approach

Work is organized around durable intents — clear outcome statements that pair automated agent generation with strict human-in-the-loop validation gates. Each intent encapsulates a functional boundary and explicit acceptance criteria.

Intent → Spec → Build

Every feature begins with a defined intent contract, camera HUD specs, and OpenAPI endpoints. Implementation is machine-validated before any UI styling or crowd testing.

Constraint as First-Class

Zero cost ($0.00 cloud budget), sub-4-second evaluation round-trip, and no-login frictionless participation are treated as non-negotiable architectural boundaries.

Clean Client / Host Split

React handles media streams and client transitions; .NET handles AI security keys, storage credentials, rate limiting, and persistence. Secret keys never leak to the browser.

Segregation of Duty

Autonomous AI agents generate client components, backend endpoints, and prompt schemas. Human graduate leads verify tone, crowd hilarity, and live kickoff readiness.

Primary Architecture Intents

I1

Frictionless Capture Intent (Webcam + Optical Guidance)

A competitor opens the app on phone or kiosk, aligns their mouth and nose with an on-screen mustache reticle, inputs their display name, and snaps a crisp close-up within 15 seconds without creating an account.

I2

Humorous Multimodal Deliberation Intent (Gemini 2.0 Flash)

The backend transmits the cropped facial hair image to Gemini with structured rubric parameters, returning a valid JSON verdict comprising an Overall Score (1-100), Sub-scores, Mustache Archetype, Celebrity Twin, and Workplace-Safe Roast in < 3.5 seconds.

I3

Zero-Cost Persistence Intent (Cloud Storage + Relational DB)

Photographs are compressed and persisted to Cloudinary/Supabase free tiers with CDN optimization, while scores, names, roasts, and timestamps are recorded in PostgreSQL/SQLite without incurring subscription charges.

I4

Real-Time Crowd Leaderboard Intent

Competitors and colleagues view live rankings with podium spotlights, archetype badges ("The Corporate Handlebar", "Peach Fuzz Prodigy"), filterable categories, and full-screen Kiosk Mode for office projection.

I5

Meme Sharecard Generation Intent

Upon receiving their score, users can download or share a high-contrast DVT-branded digital scorecard badge featuring their cropped photo, official verdict title, and judge roast to Slack or WhatsApp.

Section 06

Planning Overview — Automated & Exploratory Testing

Testing combines standard software engineering suites with specialized GenAI rubric validation to ensure stability, deterministic output parsing, and safe hilarious judging.

Unit & Domain Logic

  • Score normalization algorithms (0-100 scale bounding).
  • Leaderboard sorting, ranking, and tie-breaker logic.
  • Image size validation and MIME-type integrity checks.
  • Display name sanitization and profanity filtering.

Gemini Schema Validation

  • Contract testing on Gemini JSON response parser.
  • Mocked responses verifying fallback handling for API 429s.
  • Prompt safety regression suite verifying zero abusive words.
  • Temperature invariance testing across diverse facial inputs.

Camera & UX Testing

  • MediaDevices API permissions across iOS Safari and Android Chrome.
  • Canvas aspect-ratio scaling across portrait and landscape phones.
  • Guidance overlay alignment math on different aspect ratios.
  • Offline / low-network graceful error toasts.

End-to-End Smoke Tests

  • Full loop: Snap photo → Cloudinary upload → Gemini parse → DB record → Leaderboard display.
  • Multi-client concurrency test (10 rapid submissions).
  • Kiosk mode 2-hour continuous burn-in test without memory leaks.

CI/CD Automated Verification: Automated GitHub Actions workflow executing dotnet test for backend endpoints and npm run test && npm run build for React on every push to main.
